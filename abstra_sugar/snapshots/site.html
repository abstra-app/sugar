Sugar

A concise language that compiles to HTML, CSS, and JavaScript. Write less, build more.

Why Sugar?

One syntax for everything. Indentation-based, no closing tags, no semicolons.

style=color:var(--muted) HTML
       <div class="card">\n  <h3>Hello</h3>\n  <p>World</p>\n</div>
style=color:var(--primary) Sugar
       .card:\n h3: Hello\n p: World

Features

HTML

Implicit tags

div is implicit for classes and IDs. Child tags like li, td, option are implicit inside their parents.

JS

Clean script blocks

No function keyword, no semicolons, arrow shorthand with (x): instead of (x) =>.

CSS

Nested styles & mixins

Nesting, @keyframes, and reusable mixins with @apply — all in indentation syntax.

DATA

table!, text!, math!

Template literals for tabular data, raw text, LaTeX math, Markdown, and SVG.

HTML

Components

Define reusable components with parameters and slots. Compose them freely.

JS

Collections

Flat objects with =:, arrays with -, list comprehensions, and table!: for structured data.

Template literals

Embed different languages inside script blocks.

style=margin-bottom:8px html!:

       el.innerHTML = html!:\n h1: Hello {name}\n p: Welcome

style=margin-bottom:8px table!:

       users = table!:\n name   | age | role\n "Alice" | 30  | "admin"\n "Bob"   | 25  | "user"

style=margin-bottom:8px text!:

       msg = text!:\n Hello, {name}!\n Welcome to Sugar.

style=margin-bottom:8px svg!:

       svg! 200x200:\n circle 100 100 r=50 fill=red\n path stroke=blue:\n  M 0 0\n  L 200 200
